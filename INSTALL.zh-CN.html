先确认这份教程适合你

本教程针对第一次安装 Mod 的 Windows Steam 玩家。你只需要 Steam、官方游戏客户端、浏览器以及 Windows 自带的资源管理器与 PowerShell。

✅ 这个 Mod 做什么

在 Mod 正常加载时临时开放第二回声，并修补第二盆献祭、房间推进与沃里克二阶段等异常表现。

🛡️ 它不做什么

本 Mod 不直接将第二回声任务步骤永久写成完成；临时解锁依赖 Mod 正常加载。正常游玩仍可能保存角色和世界进度，移除 Mod 不会回滚这些存档变化。

⛔
硬性版本门槛：Steam public Build 22928553

如果游戏更新或加入测试分支，当前 Mod 可能不兼容。不要绕过版本检查；请等待兼容版本或联系作者。

⚠️
最容易装错的地方

下载的 ZIP 必须先在系统解压。最终必须看到 游戏安装目录\Mods\CrucibleUnlock.dll，而不是 ZIP 包、多层 Mods\Mods 或一整层解压文件夹。

安装或更新期间请先退出游戏。AI Agent 可以协助执行下载、复制和只读核对；按本项目工作规范，务必由用户本人通过 Steam 启动游戏并完成游戏内实机测试。

0退出游戏，备份已有存档

  1. 确认 Steam 库中游戏不显示“正在运行”，并耐心等待 Steam 云同步提示完成。
  2. 键盘按下 Win + R 调出运行窗口，粘贴下方路径后回车：
%USERPROFILE%\AppData\LocalLow\Moon Studios\NoRestForTheWicked
  1. 若看到 DataStore 文件夹，右键复制，并粘贴到桌面或安全磁盘位置。建议给备份重命名为 NRFW-save-backup-日期-时间。
  2. 确认备份副本已经完整生成；原始 DataStore 留在原位，请勿剪切或直接删除。
💡
新电脑可能还没有存档

如果从未进入过游戏，找不到 DataStore 属于正常现象。记下“没有现有存档”，继续下一步即可。

1找到真正的游戏目录，核对版本

  1. 在 Steam 库中右键《恶意不息》→ 管理 → 浏览本地文件。弹出的文件夹即为本文所指的“游戏安装目录”。请务必以此为准，不要盲猜 C 盘或 D 盘。
  2. 核实该目录下同时存在 NoRestForTheWicked.exe 和 NoRestForTheWicked_Data。
  3. 在游戏所在 Steam 库上一级 steamapps 目录中应能找到 appmanifest_1371980.acf。可用记事本打开并搜索 "buildid"，其数值必须是 22928553（且分支为 public）。
⚠️
文中路径仅作示意

诸如 D:\SteamLibrary\... 仅为示例，并非统一规范。后文提及的 Mods、MelonLoader、UserData 都应直接放在你自己电脑的游戏安装根目录。

2安装 MelonLoader 0.7.3 x64

本 Mod 安装包 不包含加载器本体。请前往 MelonLoader 官方 v0.7.3 发布页，下载适合 Windows x64 的手动解压包（MelonLoader.x64.zip）。或参考 官方安装器指南，指定 0.7.x 版本及游戏目录。

  1. 下载后在系统“下载”文件夹中右键加载器 ZIP，选择全部解压（Windows 内置解压功能即可）。
  2. 解压后，将包内文件整体移入游戏安装目录根部（即与 NoRestForTheWicked.exe 同级同层），严禁误放入 Mods 内部。
  3. 放入前先观察目标位置；若已有旧加载器文件，请先排查版本来源，避免未经核对直接覆盖。
  4. 若使用上文指定的 0.7.3 x64 手动 ZIP，放置完成后，游戏根目录应有 MelonLoader 文件夹和与主程序同层的 version.dll。官方安装器的文件清单可能不同；最终仍须在用户启动游戏后以加载日志确认。
💡
当前状态为“文件已放置”，而非“运行已生效”

加载器在首次被玩家启动时，才会自动生成 IL2CPP 互操作程序集与日志。现在可先继续配置 Mod，首轮启动留待第 6 步进行。

3从 Nexus 下载 Mod ZIP

  1. 访问 Nexus Mods：Second Crucible Unlock and Fixes 页面。
  2. 在 Main files 栏找到 Crucible Unlock 0.9.5，点击 Manual download。如需登录或验证，按页面指引完成。
  3. 在本地“下载”文件夹中找到刚下载的 ZIP。
  4. 右键 ZIP → 全部解压。打开解压后的 Mods 文件夹，找到 CrucibleUnlock.dll。

4把 DLL 放在唯一正确的位置

  1. 回到第 1 步找到的游戏安装根目录。若尚不存在 Mods 文件夹，则手动新建一个，英文大小写严格为 Mods。
  2. 将刚刚解压出的 CrucibleUnlock.dll 复制粘贴进该 Mods 目录。
  3. 核对文件最终完整结构：
<你的游戏安装目录>\Mods\CrucibleUnlock.dll
存放状态 路径示范
🟢 正确标准 游戏目录\Mods\CrucibleUnlock.dll
🔴 错误：直接塞 ZIP 游戏目录\Mods\CrucibleUnlock-0.9.5.zip
🔴 错误：嵌套双层 Mods 游戏目录\Mods\Mods\CrucibleUnlock.dll
🔴 错误：多了一层解压文件夹 游戏目录\CrucibleUnlock-0.9.5\Mods\CrucibleUnlock.dll

解压包中的 README.txt、SHA256SUMS.txt 属说明与校验文件，无需拷入游戏。若先前有同名旧版 DLL，请完全退出游戏后备份移出，请勿在 Mods 里并存多个不同名称的旧版与新版 DLL。

5写入三个必填配置项

配置文件目标位置：游戏安装目录\UserData\MelonPreferences.cfg。如果此文件已存在，使用记事本打开并保留其它 Mod 的设定；若尚未生成，可在根目录新建 UserData 文件夹，并在其内部新建 MelonPreferences.cfg（需确保 Windows 资源管理器已打开“文件扩展名”，避免误保存为 .cfg.txt）。

  1. 搜索 [CrucibleUnlock]。若已有该段落，直接修改其参数；若无，则在文末换行新增。严禁存在两个相同的 [CrucibleUnlock] 块。
  2. 确保该段落完整写入以下三行配置：
[CrucibleUnlock]
mode = "runtime-unlock"
guard_broken_warrick_music = true
repair_warrick_phase2_target = true
  1. 保存并关闭文件，重新打开核实：runtime-unlock 必须带有英文半角双引号；两个 true 全为小写且不带引号。
⚠️
仅设置 mode 并不充分

沃里克（Warrick）的两个修复开关默认均为 false。为保障二阶段流程稳定，本版本必须将三项参数完整声明。

6Mod 效果描述

安装完成后，由玩家本人通过 Steam 启动游戏。首次启动可能稍慢，进入游戏后可按下面的流程体验：

🎮
第二回声体验流程

传送至试炼中心 → 来到第二个血盆献祭 → 看到血液流出 → 进入试炼 → 开始 Boss Rush → 在后续场次遇到达拉克。

达拉克是 Boss Rush 后续场次的 Boss；第一场是沃里克。请由玩家亲自观察献祭动画、血流、Boss 和楼层推进是否正常。如果使用中遇到问题，再阅读下一节“日志核对”。

日志核对

仅在 Mod 无法正常使用时才需要查看本节。如果第二个血盆能正常献祭、进入试炼且后续玩法正常，就不必打开日志。遇到无法进入、动画异常、Boss 或楼层推进异常时，请先由玩家正常退出游戏，再按下面步骤检查或把相关日志发给作者。

  1. 使用记事本打开 游戏安装目录\MelonLoader\Latest.log，按 Ctrl + F 逐条检索以下关键词：
MelonLoader v0.7.3
Crucible Unlock 0.9.5-husk-hud-candidate 已加载
mode = runtime-unlock
guard_broken_warrick_music = True
repair_warrick_phase2_target = True
[runtime-unlock] build guard passed
[runtime-unlock] installed two targeted read overrides

这些日志项不一定相邻排列。第一项应显示实际版本，例如实测日志中的 MelonLoader v0.7.3 Open-Beta，不要逐字搜索 v0.7.x。若仅有“已加载”而缺少 build guard passed 或读取覆盖记录，不能据此认定临时解锁已生效；先检查日志是否完整以及是否存在报错。若游戏初次启动重置了该配置，退出后需重新按照第 5 步补全。

💡
需要帮忙时

你可以把报错附近的日志片段发给作者；分享前先遮住用户名、电脑路径等个人信息。不要仅凭某一行日志判断所有游戏效果是否正常。

装不上时，先按现象排查

异常现象 建议优先核查项
找不到真实游戏路径 在 Steam 中通过“管理 → 浏览本地文件”定位，不要手动生搬示例盘符。
未生成 MelonLoader 日志 确认加载器解压在 .exe 同级目录；确认是否已由玩家主动启动过游戏。
Mods 文件夹内是 ZIP 必须先在本地解压，仅将解压出的 CrucibleUnlock.dll 复制进去。
日志未提示 Mod“已加载” 检查 DLL 路径是否正确、是否误用了旧版本，以及查看加载器是否报错中断。
日志输出 mode = probe 核查配置文件全名（防止扩展名变成 .cfg.txt）及是否有冗余重复区块。
修复项始终为 False 在同一配置块内显式补充写入 true，并在游戏彻底关闭后重启生效。
版本守卫（Build guard）报错 确认 Steam public Build 是否为 22928553。若游戏已更新，请等待兼容版本或联系作者，不要绕过版本检查。
已加载但第二回声未解锁 检查日志是否包含两处覆写记录；由玩家前往正确献祭盆交互触发。
初次启动等待过久 首发加载器需要现场组装 IL2CPP 程序集，耗时属正常，请耐心等待其完成。

若需向开发者反馈故障，请备齐 Steam Build 号、MelonLoader 与 Mod 版本，并附带关键日志片段。发布前请注意打码遮蔽个人用户名、电脑磁盘名等隐私字段。

以后如何更新或卸载

  • 更新 Mod：完全退出游戏；将旧版 DLL 备份移出，按新版发布说明安装，只保留单一 CrucibleUnlock.dll。严禁游戏运行途中替换文件。
  • 单卸载本 Mod：退出游戏后直接删除 Mods\CrucibleUnlock.dll 即可。配置文件中的相关设定保留与否均不会影响游戏。
  • 卸载 MelonLoader：参考 MelonLoader 官方卸载教程移除对应组件。切勿为了卸载加载器而粗暴清空整套存档或 UserData 目录。
