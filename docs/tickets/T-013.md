- **背景**：随从的跟随、传送、卡住判定数值在召唤时从起尸数据复制进每个随从的 `RaisedMinionComponent`（跟随开始/停止距离、编队半径、索敌半径、传送距离、跟随速度、避让半径/速度），所有随从共用一套。复活的 Boss（如沃里克）打架时没有 `AttackTargetRef`，原版卡住逻辑会把它反复拉回；不同体型/种类的随从需要不同参数。
- **决定（维护者 2026-11-27）**：做成一套机制，别的 Boss 也能用；最终不同召唤物对不同表情也能有不同反应（表情→招式表由 T-012 负责，本单提供召唤物的配置键）。
- **方案**：按召唤物分档（Boss / 巨型 / 精英 / 普通）给默认行为配置，可按 NPC 资产 GUID 单独覆盖。随从出生时（`FrameEvents.RaisedMinionSpawned`）解析其 NPC 数据和敌人类型，选中配置，写入该随从组件里的复制值；卡住传送保护模式按随从各自生效（`offfollow` / `never` / `vanilla`）。对外提供「随从 → 配置名」查询给 T-012 使用。
- **分支**：`t/T-013-minion-profiles`，2026-11-28 在 `main`（含 T-011 #19、T-010/T-012 #18）上重建，只保留本单改动。
- **待确认**：默认数值以试玩调整；表情反应接口与 T-014（通用表情→招式表）对齐。
