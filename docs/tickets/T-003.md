- **在做什么**：装上三枚死灵符文后施放起尸。
- **实际**：原版 `SystemSetup.CreateSystems` 生成的 105 个系统里没有 `CorpseMarkerSystem` 和 `RaisedMinionSystem`（插件日志 `systems: CorpseMarker=False; RaisedMinion=False; total=105`）。
- **期望**：两个系统在模拟里运行。
- **修法**：后缀挂 `CreateSystems`，缺失时追加到系统数组；会话开始时检查并启用。
- **证据**：之后日志 `APPENDED missing systems` → `CorpseMarkerSystem running` / `RaisedMinionSystem running`，起尸 `Execute -> True` 多次。

- 2026-11-25 0.4.0 实机日志确认系统缺失；补系统后起尸成功。
