- **在做什么**：0.18.2（T-015 分支测试版）用 Boss 召唤符文召出沃里克、回声骑士，在塞利姆试炼中庭、第一层试炼的小怪房间里移动。
- **复现**：
  1. 镶好 Boss 召唤符文，召出沃里克或回声骑士（只限 Boss 召唤符文召出的随从）。
  2. 进入试炼中庭或第一层试炼的小怪房间，走开几米到二十米。
- **实际结果**：随从站在原地不跟着走；离开 20 米后被原版远距传回拉到身边，之后又不动，反复如此。
- **期望结果**：和 0.17.x 起尸召出的沃里克一样，离开跟随距离（3 米）后自己走过来；传回只作为兜底，距离按 T-009 为 60 米。
- **证据**（插件日志 `NRFWNecromancy.log`，0.18.2 会话，2026-11-28 18:20 起，测试角色 A）：
  - 18:23 到 18:29 之间 `branch=far` 传回 13 次，几乎都是 `ownerDist≈20 … following=False … max=20 followStart=3`：随从离主人 20 米仍不在跟随状态，只是到了传送距离才被拉回。
  - 同一份日志的 0.17.0 会话（T-010 原版 raiseMinion 换沃里克）里，传回行是 `following=True … max=60`，没有这种「不跟随 + 20 米传回」的循环。
  - 18:27:48 与 18:29:00 各有一次 5219 米、768 米的传回，对应换场景（推断是进出试炼），换场景后连续出现上面的 20 米循环。
- **已确认的一个原因（静态读代码）**：`BeforeRaiseData` 遇到 Boss 符文自己的动作（`IsPrivateBossAction`）直接返回，没有走 T-009 的传回距离 ×3，所以 Boss 符文随从的 `MaxDistanceBeforeTeleport` 还是原版 20 米（日志 `max=20`）。这解释了为什么 20 米就传回，但不解释为什么不跟随。
- **待查**：
  - 为什么 `IsFollowing` 一直是 0：Boss 符文克隆动作的跟随参数（`FollowStartDistance` 等）是否和原版 raiseMinion 一致；随从 AI（Boss AI）在没有攻击目标时是否会进入跟随；试炼场景的导航网格下寻路是否失败（T-011 的 `GUARD`／`NO-NAV` 行本次 0 条）。
  - 普通世界地图里是否也一样（维护者目前只在试炼中庭、第一层试炼里注意到）。
  - 原版 raiseMinion（非 Boss 符文）在同样场景是否正常，用来区分是 T-015 克隆动作的问题还是场景问题。
