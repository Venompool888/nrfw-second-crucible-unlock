## 目标

将 `src/Necromancy/NecromancyMod.cs`（约 1572 行）按职责拆分为独立的 `partial class NecromancyMod` 模块文件，升级插件版本至 `0.19.0`，并补齐以下稳定性与性能改造（同时 100% 保留 T-014 表情反应和 T-015 Boss 符文行为）：

1. **无哈希 Steam 版本门控（`NecromancyBuildGuard.cs`）**：在安装任何 Harmony 或 Native hook 之前，校验 `appmanifest_1371980.acf` 的 `buildid == "22928553"`，并确认 `GameAssembly.dll` 与 `NoRestForTheWicked_Data/il2cpp_data/Metadata/global-metadata.dat` 存在且大小大于 0（遵守项目 2026-10-19 无哈希约定，不计算 SHA256）。清单解析纯逻辑放在 `NecromancyPolicy`。
2. **集中式会话状态重置（`NecromancySession.cs`）**：在 `AfterCreateSystems` 调用 `ResetSessionState()`，原子清空全部会话级集合与状态标记。
3. **主线程异步配置重载与缓冲日志（`SystemRegistration.cs`、`NecromancyLog.cs`）**：
   - `AfterCreateSystems` 不再同步读写反应表 JSON，仅置 `_reactionsReloadRequested = true`，由 `OnUpdate()` 在主线程泵入 `LoadReactions(force: false)`（`InstallRoarCommand` 仍负责启动时首次加载）。
   - 用带缓冲的 `StreamWriter`（`FileShare.ReadWrite`、懒打开、批次与定时/退出刷盘、失败降级）替代每帧 `File.AppendAllLines`。
4. **O(1) 随从视图查找（`MinionVisuals.cs`）**：用 `EntityViewTracker.TryGetByEntityRef` 替代全场景 `UnityEngine.Object.FindObjectsOfType`。
5. **功能级故障隔离与安全退出**：
   - 非关键功能（`diagnostics`、`visuals`、`roster`、`roar`、`teleport-hold`）各自记录错误并只关闭自身，绝不翻转全局 `_enabled = false`。
   - 用 `OnApplicationQuit()` 替代 `OnDeinitializeMelon()`：置 `_damageProtectionActive = false`、`_enabled = false`，刷盘并释放日志流，退出阶段不调用 `NativeHook.Detach()`，也不触碰 IL2CPP 对象。
6. **Teleport Guard 归属与帧引用清理（`MinionTeleportGuard.cs`）**：将 `RaisedMinionSystem.Update` 的 Prefix 与 Postfix 合并到同一 Harmony owner，并在 `AfterRaisedUpdate` 及异常路径显式置 `_simFrame = null`。
7. **空随从伤害快路径（`MinionDamage.cs`）**：在 `BeforeResolveRaisedDamage` 与 `BeforeRaisedProjectileImpact` 前先判断 `NecromancyPolicy.ShouldInspectDamage(...)`，无活跃或历史随从时跳过 `new Frame` 与组件查询，直通原版 trampoline。
8. **审计与纯逻辑回归测试**：更新 `tools/NecromancyHookAudit/Program.cs`，新增纯 C# 回归测试项目 `tests/NecromancyCoreTests/`。
