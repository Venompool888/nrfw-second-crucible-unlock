# T-009 随从传回距离拉远到 3 倍

- **背景**：随从离玩家超过原版 `RaiseMinionActionData.MaxDistanceBeforeTeleport`（20 米）会自己传送回玩家身边，维护者觉得太近。
- **决定（维护者 2026-11-26）**：距离至少拉到现在的 3 倍。新增配置 `minion_teleport_distance_multiplier`，默认 3（60 米），1 = 原版，≤0 视为原版，上限 50 倍。
- **实现**：`RaiseMinionActionData.Execute` / `CanRaiseNearby` 前缀按倍数改资产的 `MaxDistanceBeforeTeleport`，按资产指针记下写入值避免重复放大；资产重载回原值时会再放大一次。
- **待确认**：随从离远后是否仍正常跟回、区域切换（快速旅行）是否仍会传回。

## 进度记录

- 2026-11-26 维护者要求传回距离至少 3 倍；定位到原版字段 `RaiseMinionActionData.MaxDistanceBeforeTeleport` = 20 米；0.13.0 实现（默认 3 倍 = 60 米），离线审计 57/57，已安装，待试玩。
- 2026-11-26 0.13.0 试玩日志：两份起尸数据（起尸、复活）各放大一次 `20 -> 60 m`，但没有传送事件记录，无法核实实际距离。0.13.1 挂 `Frame.FrameEvents.RaisedMinionTeleported` 记 `minion TELEPORTED … moved=… m`，审计 62/62，已安装，待试玩。
- 2026-11-26 静态分析（T-011）：距离值在召唤时复制进 `RaisedMinionComponent+0x50`，改资产只影响之后召出的随从（插件在 Execute 前改，覆盖全部）；快速旅行时 ~790 米的传回走的就是距离分支。但 0.13.1 日志里频繁的 2.8~24.5 米传送是「卡住」分支（跟随中或有攻击目标、3 秒内移动不到 0.5 米），与倍数无关；维护者看到的「打架时被拉回」很可能就是它。是否改卡住传送待维护者决定。
