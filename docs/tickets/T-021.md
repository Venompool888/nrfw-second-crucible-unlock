## 目标

制作独立 MelonLoader 插件 `NRFWPerformance`，针对公测版 `public / 22928553`（`MoonRenderPipeline` + `UberGCLogic` + Quantum）在肉眼几乎无损的前提下大幅提升帧率、改善 1% Low、消除活跃游玩期半秒级顿卡，并提供实时渲染诊断与无损 A/B 对比。

## 逆向实锤（公测 `22928553` / Build `29466`）

1. **`iMXAO` 全分辨率锁死**：`MoonRenderPipelineAsset.UpdateQualityPreset` 在 Low/Med/High/Ultra 全部硬编码 `iMXAOShadingRate = Full (0)`，但管线原生自带 `Half (1)` 半分辨率时序历史重投影（`m_AOHistoryRT`）与双边滤波（`iMXAOFilterSize = 2`）。
2. **`FlashLight` 接触补光在 FSR/DLSS 下强锁全分辨率**：`FlashLightGetDepthMipIndex` 在 `DLSSEnabled() || FSREnabled()` 时强设 mip `0`，且 `FlashLightResDividerMinRes = 1441` 卡掉 1440p（`1440 < 1441`），每像素跑 `16` 主步 + `4` 侧步深度采样。
3. **`HalfResTransparencyScale` 在 High/Ultra 为 `1.0`**：开启 FSR 时透明拆分与双边上采样固定开销每帧都在运行，但 High/Ultra 缩放为 `1.0`，粒子/烟火仍按 100% 内部分辨率渲染。
4. **High/Ultra 采样与剔除冗余**：粒子投射阴影（`ExcludePareticleSystemShadowCasters = false`）、Ultra 主光源阴影 `4096` 与 `PCSS 8/8/16`、High/Ultra 体积雾全分辨率深度步进（`VolumetricUseLowResDepth = false`）、SSR `32/64` 步、平面反射 `0.5/0.75 × 3` 相机重绘、远景小物体剔除过松（`0.02/0.01`）。
5. **活跃游玩期 `UnloadUnusedAssets` 顿卡**：`Player.log` 实测多次主线程卡死 `292–596 ms`（扫描 101–166 万对象）；内存充裕 PC 可通过 `UberGCLogic.ShouldRunCleanup` 拦截活跃游玩期的 `Proactive / Panic` 卸载，仅保留黑屏过场/传送与低内存兜底卸载。
6. **Job Worker 线程锁定**：`MoonRenderPipelineAsset` 默认 `LimitWorkerThreadCnt = Always (2)`、`WorkerThreadCnt = 8`，在多核 CPU 上压低了工作线程数。
7. **Streaming 梯子实体异常风暴**：`Quantum.LadderData.KickDown` 对缺少 `PhysicsComponent` 的流式实体反复抛出 `InvalidOperationException`（单次会话 26–77 次 × 42 行堆栈）。

## 方案

- **Tier 1（零画质代价）**：解锁 Worker 线程、拦截内存充足时的活跃期 `Proactive/Panic` 资源卸载、守卫 `LadderData.KickDown` 缺 `PhysicsComponent` 实体、开启粒子阴影剔除。
- **Tier 2（肉眼近无损 GPU 提速）**：`UltraSmart`（默认）/ `BalancedPro` / `MaxFps` / `Vanilla` 预设，支持 `MelonPreferences` 与 `F9` 面板逐项热调；改前完整快照原版 `MoonRenderPipelineAsset` 与 `MoonClothUpdate` 值，并在 `UpdateQualityPreset` 后自动重新采集并覆盖，确保 `F10` 无损瞬时 A/B 切换。
- **Phase 0（实时诊断）**：`F9` 开关轻量 HUD（FPS / 1% Low / GPU & CPU ms / 渲染分辨率 / Pass 采样器状态 / 预设与开关），`F10` 瞬时 A/B 切换，`F11` 输出完整快照至 `UserData/NRFWPerformance.log`。

## 测试与验收

- **第 1 层**：`PerformancePolicyTests`（预设表、解析与越界输入、FlashLight Mip 夹紧、透明缩放、GC 拦截矩阵、阴影分辨率封顶、帧统计环形缓冲与负向输入测试）+ `PerformanceHookAudit`（PE 只读元数据校验所有 hook 与管线成员签名，且确认不碰 `GetActionView` / `InitializeResourceManager`）。
- **第 2 层**：`verify-local.ps1`。
- **第 3 层（维护者试玩）**：
  - `F9` 开关面板，查看 FPS / 1% Low / GPU ms / 渲染分辨率与逐项热调。
  - `F10` 在 `Vanilla` 与 `UltraSmart` 之间瞬时 A/B 对比，核对帧数/GPU 耗时变化与画质观感。
  - `F11` 导出快照，检查 `UserData/NRFWPerformance.log` 与游戏 `Player.log`（确认活跃游玩期不再出现半秒级 `UnloadUnusedAssets` 冻屏和 `LadderData.KickDown` 异常风暴）。
