【恶意不息】第二回声解锁mod安装教程

Steam 版《恶意不息》· Build 22928553 · Mod 0.9.5

1准备工作

  1. 下载 Melonloader
  2. 下载 CrucibleUnlock.dll
  3. 下载 MelonPreferences.cfg

2安装 Melonloader

选择游戏 《恶意不息》

点击 安装（install）

安装完毕

3放置 CrucibleUnlock.dll

进入 📂 Mods 文件夹

放置 CrucibleUnlock.dll

4放置 MelonPreferences.cfg

进入 📂 UserData

放置 MelonPreferences.cfg

⚠️ 如果你之前装过别的 Mod，UserData 里可能已经有 MelonPreferences.cfg 了——不要直接覆盖，请看文末的《已经有 MelonPreferences.cfg 的玩家》。

5启动游戏

第一次启动可能较慢，后续会很快

BOSS RUSH 愉快！

已经有 MelonPreferences.cfg 的玩家（重要）

UserData\MelonPreferences.cfg 是 MelonLoader 给所有 Mod 共用的同一个配置文件。只要你之前装过别的 Mod，或者游戏已经启动过一次，这个文件就已经存在了。这时候把下载来的 cfg 直接覆盖进去，会把你其他 Mod 的设置一起删掉。

该怎么做

  1. 先把现有的 UserData\MelonPreferences.cfg 复制一份到别处备份。
  2. 用记事本打开它。
  3. 在文件末尾追加下面这一整段；如果里面已经有 [CrucibleUnlock]，就改这个区块里的值，不要再新建第二个 [CrucibleUnlock]。
[CrucibleUnlock]
mode = "runtime-unlock"
guard_broken_warrick_music = true
repair_warrick_phase2_target = true
repair_bossrush_progression = true
repair_ritual_animator = true
trace_boss_motion = false
boss_trace_drop_amount = 300
  1. 保存并关闭，然后重新启动游戏。

对照你的情况

你的情况怎么做
从没装过 Mod，UserData 里没有 cfg直接把下载的 MelonPreferences.cfg 放进 UserData\
有 cfg，但里面没有 [CrucibleUnlock]把上面那段追加到文件末尾
有 cfg，里面已经有 [CrucibleUnlock]只改这个区块里的值，保留其他 Mod 的区块
改乱了，想从头来先备份，再删掉 cfg；MelonLoader 下次启动会重新生成默认配置（其他 Mod 的设置会回到默认值）
放置 DLL 和修改 cfg 时，游戏必须完全退出。另外请打开 Windows 的“显示文件扩展名”，确认文件名是 MelonPreferences.cfg 而不是 MelonPreferences.cfg.txt。
